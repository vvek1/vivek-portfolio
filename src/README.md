# Source Structure

- `App.jsx` — application shell and page composition.
- `main.jsx` — React/Vite entry point.
- `components/common/` — reusable UI components such as splash screen, dock and hire modal.
- `components/cards/` — project and experience card components.
- `data/portfolio.js` — portfolio content data (projects, experience and stack).
- `styles/index.css` — global/base styles.
- `styles/App.css` — portfolio component and page styles.
- `assets/images/` — image assets.
- `assets/icons/` — SVG/icon assets.
